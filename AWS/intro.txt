# Amazon Machine Image (AMI):
- An Amazon Machine Image is a pre-configured template that provides the necessary information to launch an EC2 instance in AWS.
- It includes
    - Operating system
    - Application server
    - Pre-installed software and configurations

# How to create an Image:
- select instance -> Actions -> Image and Templates -> Create Image

# AWS ELB & ASG Service

# Elastic Load Balancer Points:
- Distributes Traffic: It splits incoming traffic across multiple servers so no single server gets overloaded.
- Improves Availability: If one server goes down, the load balancer automatically sends traffic to the working servers, ensuring your application stays available.
- Scale Resources: It helps manage high demand by adding more servers during peak times and distributing the load.
- Single point of access need to be expose.
- High availability across availability zones.

# Types of Load Balancers:

1. Application load balancer: is perfect for web applications, handling complex HTTP and HTTPS requests.
2. Network load balancer: is designed for high-performance and low latency, perfect for TCP/UDP traffic.
3. Gateway load balancer: helps deploy, scale and manage third-party virtual applications, such as firewalls and monitoring solutions.

# Auto Scaling Group (ASG):
- ASG is a service that automatically add or remove EC2 instances based on demand to ensure your application is always available.
- It helps scale up when more capacity is needed and scale down during low usage to save costs, keeping the right number of servers running at all times.

# Functions of ASG:

1. Automatic Scaling: Scale the number of EC2 instances up or down based on demand.
2. Maintain instance health: Replace unhealthy instances automatically to ensure reliability.
3. Use scaling policies: Set rules for scaling based on metrics like CPU usage or request count.
4. Ensure Availability: Alwats keep a defined number of instances running to meet application needs.
5. Schedule scaling: Pre-configure scaling activities for specific times.
6. Distribute instances: Deploy instance across multiple availability zones for high availability. 
7. Integrate with ELB: Attach instances to an Elastic Load Balancer to automatically balance traffic.
8. Optimize costs: Scale down during low demand to save on infrastructure costs.

# AWS Simple Storage Service (S3) Bucket:
- AWS S3 is a cloud based storage service that allows you to store, manage and retrieve large amounts of data like files, image, videos and backups securely and at scale.
- It provides highly reliable, scalable object storage, making your data accessible from anywhere, anytime via the internet.

# Key points:
- store data as objects.
- globally unique name.
- region specific.
- each object within a bucket is stored as a key-value pair.
- Maximum object size: 5TB is the maximum size for a single object in Amazon S3.
- Multipart upload is recommended for objects larger than 5GB.

# How to create Bucket:
- S3 -> Create Bucket or General purpose buckets

# Static Website Hosting:
- Open Bucket -> Properties -> Static website hosting -> EDIT -> Enable Static website hosting -> Hosting type(host a static website) -> index document(index.html) -> save

# Permissions:
- Open Bucket -> Permissions -> Block Public Access (bucket settings) -> EDIT -> Uncheck Block all public access -> save

# S3 Bucket Policies:
- JSON-based access control policies that you attach directly to S3 bucket to manage permissions for accessing the bucket and its objects.
- They allow you to define who can access the data and what actions they can performs, such as read, write or delete, enabling fine-grained control over the security of your data stored in S3.

# Permissions:
- Open Bucket -> Permissions -> Bucket Policy -> EDIT -> Policy generator -> Save changes.

# S3 Versioning:
- It allows you to keep multiple versions of an object in the same bucket, providing protection against accidental deletions or overwrites.
- When versioning is enabled, S3 stores every versions of an object, allowing you to recover older version if needed, making ideal for data safety and backup.

- Open bucket -> Properties -> Bucket versioning -> EDIT -> Enable -> save.

# S3 Replication:
- It allow you to automatically copy objects from one S3 bucket to another, which can be,
    - within the same region (same region replication)
    - in different region (cross region replication)

- It is commonly used for compliance, redundancy, and to improve data access performance by maintaining copies closer to your users.

# How to do S3 Replication:
1. create new bucket
2. open old bucket -> management -> replication rules -> create replication rules -> save -> Replicate existing objects? -> yes -> submit -> create batch operations job -> save

# S3 Storage Classes:
- open bucket -> click on object -> storage class -> EDIT -> save

# S3 Bucket Lifecycle:
- We can use lifecycle policies to control the movement of objects between different storage classes or delete them entirely, based on specific conditions like age or inactivity.
- open bucket -> management -> create lifecycle rule -> save
